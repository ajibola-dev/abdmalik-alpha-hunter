# abdmalik-alpha-hunter

Autonomous Web3 farming intelligence bot. Built by [@devajibola](https://twitter.com/devajibola).

Monitors proven alpha callers on X and GitHub to surface early-stage crypto projects in the 4 verticals that have historically produced the biggest airdrops — ZK/L2, PerpDEX, Solana DeFi, Cosmos/DA — before they trend on Galxe or hit 50K Discord members.

**Stack:** Python 3.11 · SQLite · Telegram · RapidAPI · GitHub API

**Deployment:** Railway / Oracle Cloud
